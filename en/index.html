P—03 · AmPay in production

Event-driven payment analytics

The platform processes payments across several providers. Analytics queried PostgreSQL directly, competing with transaction processing and leaving reports hours behind. I moved analytics to a Kafka event stream, reducing data lag to tens of seconds. Events are published through a transactional outbox to avoid the dual-write gap between committing the database transaction and publishing the event. I also built a payment status notification service and moved processing to an asynchronous workflow.

02 — stack

How I work

Services & APIs

I use FastAPI for standalone API services with typed contracts and asynchronous integrations. For applications with complex business logic, Django and DRF let me move faster with a mature ORM, admin interface and ecosystem. I define contracts in Pydantic and test critical integrations against a real database and message queue.

FastAPI Django DRF pytest

Data & queues

PostgreSQL is the primary data store, with composite and partial indexes for reporting queries. Celery handles heavy background work. Events are published to Kafka through a transactional outbox to avoid the dual-write gap between committing the database transaction and publishing the event.

PostgreSQL Redis Kafka Celery ClickHouse

Production & observability

Services run on Kubernetes with liveness and readiness probes. GitLab CI handles builds and deployments; Prometheus and Grafana provide metrics and dashboards. Alerts cover stalled payment processing as well as 5xx errors. After an incident with a CPU-bound scoring service, I stopped carrying concurrency settings across environments blindly: worker counts are derived from actual CPU resources and load tests run against production-like capacity.

Docker Kubernetes GitLab CI Prometheus Grafana

ML & agents

ML scoring runs as a separate service and returns the model version with each result so decisions can be traced later. I build agents with LangGraph, using explicit workflow steps, iteration limits and a log of every tool call.

LangGraph LangChain MCP Pandas NumPy
